# Eski Nitter notebook'ları

Bu notebook'lar [ntscraper](https://pypi.org/project/ntscraper/) ile çalışır. ntscraper, herkese açık Nitter
sunucularını kullanır. Bu sunucuların çoğu 2024'te kapandığı için notebook'lar artık genelde
`IndexError: list index out of range` hatası veriyor (çalışan sunucu bulunamıyor).

Bunlar yalnızca referans için saklanıyor. Güncel yöntem için ana dizindeki `scraper.py` dosyasını kullanın.
